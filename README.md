This project focuses on predicting the impact level of earthquakes using machine learning techniques.  
The model classifies earthquakes into categories such as **Low**, **Medium**, and **High** impact based on seismic features.

The goal of the project is to demonstrate an end-to-end machine learning workflow including data preprocessing, feature engineering, model training, and evaluation.

---

## Problem Statement
Earthquakes vary in intensity and impact.  
This project uses historical seismic data to build a classification model that predicts the impact level based on features such as:

- Magnitude
- Depth
- Location-based attributes



## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab



## Machine Learning Workflow
1. Data collection
2. Data cleaning and preprocessing
3. Feature engineering
4. Model selection
5. Model training
6. Model evaluation



## Models Used
- Logistic Regression
- Decision Tree
- Random Forest 


## Evaluation Metrics
- Accuracy
- F1-score
- Confusion Matrix
